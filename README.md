# ¿Qué Comemos? 🌮

Authentic hole-in-the-wall Mexican recipe discovery app built with React + TypeScript + Tailwind CSS.

## Features

- **Recipe Browser** — 18 authentic recipes with search, category filters, difficulty/spice filters, and 6 sort options
- **My Fridge** — Select toppings you have on hand and get matching recipe suggestions ranked by fit
- **Weekly Meal Planner** — Assign lunch and dinner for each day of the week; auto-generates a printable shopping list
- **Favorites** — Save recipes and access them instantly, persisted to localStorage
- **Add Your Own** — Full form to add custom recipes with ingredients, toppings, instructions, and tags

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- [Vite](https://vite.dev/) + [React 19](https://react.dev/) + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com/) via `@tailwindcss/vite`
- [Zustand](https://zustand-demo.pmnd.rs/) for state management (persisted)
- [Lucide React](https://lucide.dev/) for icons
